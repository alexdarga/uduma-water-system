# Uduma Water Management System

Système de gestion des points d'eau pour le projet Uduma, incluant une API REST FastAPI, une interface Streamlit, et une base de données SQLite.

## 🚀 Fonctionnalités

- Gestion des points d'eau et relevés de compteurs
- Calcul automatique de la consommation mensuelle
- Détection d'anomalies (compteurs défaillants, revenus sans consommation)
- Tableaux de bord interactifs avec visualisations
- API REST complète avec documentation automatique
- Interface web responsive avec Streamlit
